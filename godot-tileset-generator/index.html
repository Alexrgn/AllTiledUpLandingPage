Godot 4 workflow

Create autotile terrain for Godot without rebuilding transitions by hand.

All Tiled Up helps you generate materials, paint and verify terrain, then export a Godot 4 TileSet workflow as part of a broader multi-engine pipeline.

Try All Tiled UpLearn about autotiling

Can All Tiled Up export to Godot? Yes. The project documents a Godot 4 .tres TileSet export workflow, alongside Tiled, Unity, GameMaker, Defold, LDtk, PNG, and JSON outputs.

A Godot-oriented workflow

  1. Generate or import the materials you want to use.
  2. Create Wang, Blob, Corner, or other supported autotile transitions.
  3. Paint a test map to inspect edges, corners, ramps, and layered terrain.
  4. Verify the map and export the Godot 4 TileSet workflow.
  5. Continue scene assembly and gameplay work in Godot.

Useful for more than a single engine

The same source map can be tested before choosing an output format. That makes the editor useful when you prototype across Godot and other engines rather than committing to a separate atlas workflow for each target.
