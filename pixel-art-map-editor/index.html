Pixel-art map editor

Paint pixel-art maps with terrain rules, layers, and live previews.

All Tiled Up is a map editor for pixel artists and game developers. Generate or import materials, paint terrain with autotiling, add layers and props, test water and elevation, and export the map for your project.

Try it on itch.ioGet the Android app

What is a pixel-art map editor? It is a tool for arranging pixel-based terrain and objects into a playable map. All Tiled Up adds procedural materials, autotile transitions, layered terrain, ramps, caves, stamps, props, and export validation to that editing loop.

Build maps with more than a flat canvas

Terrain and layers

Paint rivers, coastlines, cliffs, biome edges, ramps, elevation, caves, and multi-layer terrain with directional lighting.

Water simulation

Let pools fill, drain, and redistribute across terrain. Tune wave height, flow speed, and flow direction, or use the sponge tool.

Decals and props

Scatter built-in props or import custom PNG decals such as trees, flowers, ruins, and signs.

Large-world tools

Chunk large maps for performance, then stitch and export them as a seamless result.

For more than one kind of game

The project also includes platformer level-building workflows with test play, plus hexcrawl and VTT map tools with points of interest, rivers, roads, and fog.
