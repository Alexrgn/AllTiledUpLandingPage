Wang tiles

Generate Wang tiles and see the seams in a real map.

All Tiled Up uses procedural materials and autotile logic to help you create Wang-style transitions, paint them in context, and export them to a supported game-engine workflow.

Try it in the browserCompare autotile workflows

What are Wang tiles? Wang tiles are tiles whose edges carry matching colors or labels. A map renderer can choose tiles whose neighboring edges agree, creating continuous terrain transitions without hand-selecting every corner.

Use Wang tiles in context

Start with two materials, blend them, and tune the transition parameters. Then paint a map with coastlines, rivers, cliffs, or biome boundaries. The map view reveals whether the edge and corner rules behave correctly across longer shapes.

Wang workflow features

Material blending

Import two material tiles and tune edge softness, wobble, corner rounding, and transition strength.

Paint testing

Use real terrain painting to test the rules instead of judging the atlas in isolation.

Format detection

Analyze existing atlases with the detector to identify Wang, Blob, and Corner-style arrangements.

Multiple outputs

Export PNG, JSON, Tiled/TMX, Godot, Unity, GameMaker, Defold, and LDtk workflows where supported.
