Procedural map forge for game makers

Build tile worlds without starting from a blank grid.

All Tiled Up is a procedural tileset generator and autotile map editor for game developers and pixel artists. Generate materials, paint maps, inspect tilesets, and export assets for your existing workflow.

One workspace for the tile pipeline

Use the editor to move from procedural material ideas to hand-authored maps and engine-ready exports. The feature descriptions below reflect the current project documentation.

Procedural materials

Generate substrates from seeds, frequency, palette controls, archetypes, and world presets. Tune the look before you start painting.

Autotile painting

Paint terrain while the selected rules choose edge, corner, and transition tiles. Work with Wang, Blob, Corner, ISO, and other formats.

Multi-terrain maps

Build layered maps with terrain, structures, elevation, ramps, caves, stamps, and prefabs instead of treating every tile as an isolated square.

Import and analyze

Bring in hand-drawn or generated textures, clean palettes, make them seamless, and inspect existing sprite sheets for tile rules.

Game-engine exports

Export PNG renders, Tiled/TMX data, JSON, and engine-oriented packages for workflows including Godot, Unity, RPG Maker, and more.

Designed for touch

Use pinch zoom, two-finger panning, swipeable controls, larger tap targets, and mobile-friendly navigation on supported builds.

Live water simulation

Simulate pools that fill, drain, and redistribute across terrain. Tune wave height, flow speed, and direction, or clear water with the sponge tool.

Voxel and 2.5D tools

Explore a block-world voxel sandbox with micro-props, plus isometric wall tiles and stamps for layered scenes.

Level and campaign maps

Build platformer levels with moving platforms and test play, or create hexcrawl and VTT maps with points of interest, roads, rivers, and fog.

Questions about All Tiled Up

What is All Tiled Up?

All Tiled Up is a procedural tileset generator and map-painting tool for creating autotile-ready game assets. It combines material generation, manual painting, tileset analysis, and export tools.

Who is it for?

It is designed for game developers, level designers, pixel artists, and hobbyists who need to create or test tile-based terrain and maps.

Can I use it with Godot, Unity, or Tiled?

The project includes export workflows for PNG, Tiled/TMX, JSON, and engine-oriented formats including Godot and Unity. Check the current project documentation for the latest export details.

Does it work offline?

The editor is designed to work offline for core editing. Some platform-specific features, such as updates, rewarded ads, or purchases, may require an internet connection.

Where can I find the source and updates?

The official source and project documentation are available on GitHub.
