Unity workflow

Prepare autotile terrain for Unity with a test-first workflow.

All Tiled Up combines procedural materials, map painting, and export validation so you can inspect how terrain transitions behave before bringing them into a Unity project.

Try All Tiled UpStart with tileset generation

Can All Tiled Up export to Unity? Yes. The project documents a Unity RuleTile workflow with its supporting .meta data, alongside other engine exports.

What to test before export

Terrain boundaries

Paint coastlines, cliffs, rivers, and biome edges to expose missing or mismatched transitions.

Layer behavior

Use multi-layer terrain, ramps, edge shadows, directional lighting, and stamps to test a more realistic level slice.

Atlas detection

Bring an existing atlas into the detector when you need to understand its autotiling format before replacing or extending it.

Export verification

Check the reconstruction workflow before moving the asset into Unity, reducing surprises at import time.

Keep the source map useful

A good export workflow keeps the map and its rules understandable outside a single rendered image. All Tiled Up preserves the map-oriented step so the exported asset can be checked against what you actually painted.
